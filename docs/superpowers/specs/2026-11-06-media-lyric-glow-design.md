# 媒体插件：已读歌词发光强度

日期：2026-11-06。用户已选择：默认 70%，紧凑态和展开态共同生效。

## 目标与界面

在「设置 → 插件 → 媒体插件详情」现有歌词设置中增加「已读歌词发光强度」滑块，位于歌词偏移设置附近。范围 0–100%，步长 5%，默认 70%。提供中文和英文标题、说明；说明明确该项控制已读部分的光晕，不影响文字高亮。

- 0%：不绘制光晕，仍保留已读文字颜色及逐字高亮。
- 70%：新的默认值，包括已有用户没有该配置项的情况。
- 100%：与修改前的两层光晕强度一致。
- 紧凑胶囊、展开媒体卡片及其完整歌词显示使用同一数值。

不新增全局外观选项，不改变歌词偏移、封面取色、字体、未读文字、歌词时间轴或其他材质发光。

## 数据与实现边界

沿用内置媒体插件的声明式 Slider 贡献和宿主设置存储。键名为 `media.lyricGlowStrength`，持久化数值为百分比 0–100。

沿用 `MediaPillPreferences` 的媒体插件配置读取入口，将值归一化后传入原生岛渲染模型及 `KaraokeText.Draw`。不让渲染器读取文件。设置变更要主动触发岛重绘，使暂停播放或空闲时调整也能生效；避免为此新增轮询或每帧磁盘读取。

光晕强度仅乘在现有近层 / 远层光晕的不透明度上，保持模糊半径、裁剪范围和清晰文字绘制不变。0% 时跳过两层光晕绘制。

## 兼容与错误处理

缺失、无法解析或非有限数值回退至 70%；有限的越界值夹到 0–100。沿用宿主的配置保存、恢复默认与错误反馈机制，避免引入另一份持久化文件。配置读取失败不能让岛崩溃。

## 验收与测试

1. 插件贡献包含正确的键名、默认值、范围、步长、百分比单位和本地化文本。
2. 配置解析覆盖缺失、非法、非有限、边界、越界与正常数值，重启后读回设置。
3. 紧凑与展开模型都传入同一强度；设置调整后不重启即生效，暂停播放时也刷新。
4. 渲染测试验证 0% 无光晕、70% 弱于 100%，且清晰已读文字 / 未读文字和逐字范围保持不变。
5. 运行相关 Builtin / Island / UI 测试，构建应用；使用独立配置进行原生窗口检查。
6. 更新变更记录、当前状态和相关用户说明，记录真实验证结果；不把现有截图冒称修改后拍摄。
