# 设置面板主题渐变切换设计

## 目标

将设置面板的日间/夜间主题从瞬间切换改为平滑颜色渐变，同时保留现有主题按钮的滑块、星星和云朵动画。

## 方案

- 日间与夜间切换时，对现有主题资源中的 `SolidColorBrush.Color` 执行 350ms 缓出动画。
- 对背景、侧栏和标题卡片渐变画刷的每个 `GradientStop.Color` 执行相同动画。
- 启动加载已保存主题时继续瞬间应用，避免窗口首次出现时多余播放动画。
- 连续切换时，先移除前一次动画，再从当前画刷颜色向新主题目标色过渡。

## 范围

仅修改 `SettingsWindow.xaml.cs` 的主题资源应用逻辑；不改动主题配置格式、主题按钮 XAML Storyboard 或主灵动岛外观。

## 验证

- 切换日间/夜间主题时，设置页各主题颜色在约 350ms 内平滑转换。
- 主题按钮现有动画保持正常。
- 首次打开设置页不播放主题切换动画。
- `dotnet build` 无警告、无错误。
