# FluidBar 4.1.0（2026-11-02）

本次更新完善文件暂存和内容卡片，并修复插件启动、通知与日志稳定性。

## 文件暂存

- 修复拖入时卡片展开、松手却无法放入的问题。
- 按住文件行可直接拖到文件夹或接收文件的应用，松手复制，Esc 取消；原文件和暂存引用都会保留。
- 拖出卡片后持续显示文件图标、名称、数量和复制提示。
- 暂存非空时，胶囊显示文件状态，点击可回到文件卡片；支持复制全部、移除、清空和重启恢复引用。
- 文件名称与父目录分层显示，长文件名最多两行，列表可滚动；文件暂存仍为可选插件，默认不安装。

## 内容与稳定性

- 剪贴板使用两行摘要和独立操作区域，文件摘要优先显示名称；复制保留完整原始内容。
- 修复媒体、剪贴板、通知、Agent、设备五个内置插件因能力清单为空而初始化失败。
- 通知单条解析异常单独隔离并退避重试，避免持续刷日志；应用元数据失效时保留可读取的正文。
- 日志保留原始异常类型、错误码和堆栈；媒体/位置诊断默认关闭，开启后脱敏、后台写入并限制文件大小及数量。
- 天气自动定位优先使用 Windows 定位，减少代理 IP 导致的位置偏差。

## 下载与升级

- 本地 Release 回归 2892 项通过，覆盖核心、SDK、渲染、界面、插件、Windows 平台和集成流程。
- **FluidBar.exe**：Windows x64 自包含单文件，供直接运行或应用内更新，无需额外安装 .NET。
- **FluidBar-4.1.0-win-x64.zip**：同版本压缩包。
- **publish-4.1.0.json**：版本、构建提交与文件 SHA-256 校验信息。

从托盘退出旧版后运行新版即可。已安装文件暂存的用户可继续使用；文件暂存 1.0.3 通过插件市场单独更新，要求 FluidBar 4.1.0 或更新版本，保留可选安装策略。

延续 4.0 的未签名发行方式，应用内更新强制校验 GitHub Release 资产 SHA-256。旧通知瞬时异常未能在当前通知中复现，本次增加容错与完整诊断，便于继续定位。
