# FluidBar 5.0.0（2026-11-10）

本次更新统一软件图标，完善详情页滚动，并修复液态玻璃意外透字和通知回车显示为方框的问题。

## 统一的软件图标

- 使用原版蓝色液面图标，EXE、系统托盘、原生岛窗口、设置及其他窗口 / 任务栏、关于页共用同一套资源。
- ICO 包含 16、20、24、32、40、48、64、128、256 像素，系统托盘直接加载对应的小尺寸，避免从 EXE 提取单一尺寸后缩放。
- 窗口图标通过应用样式统一设置，托盘缓存按图标内容命名，避免沿用旧资源。
- SVG 源文件与图标生成脚本随源码提供，日常构建直接使用已生成的资源。

## 更顺手的详情页

- 主页、媒体、通知列表与详情、剪贴板、Agent、小组件和文件暂存等可滚动页面共用滚动条布局。
- 滚动条支持拖动与点击定位；鼠标移出窗口仍可继续拖动，松手结束；拖动期间不会自动收起，切换页面会结束旧拖动。
- 鼠标滚轮平滑滚动，反向操作立即响应；触控板的小幅连续输入直接跟随。
- 普通纵向滚轮只滚动当前内容，在空列表或边界也不误切页。切页继续使用侧栏、横向滚轮或 Shift＋滚轮。
- 修正 Agent 页底部部分可见行的绘制，减少滚动时的空缺和跳动。
- 通知长文的换行缓存按文本内容复用，首次排版缩小到每行附近的测量范围，减少滚动中的重复排版。

## 液态玻璃修复

- 修正截图中未定义、为零或非满值的 Alpha 通道；进入模糊滤镜前把已合成的桌面 RGB 作为不透明背景处理，避免模糊图本身变透明、只剩染色层。
- 模糊边缘采用 Clamp，避免透明边缘混入玻璃背景。
- 材质切入 / 切出时保留完整的模糊背景；采样不可用时使用更实的底色回退，避免后方文字直接透出。
- 补充透明通道、颜色保留、模糊效果及可选的真实 Windows 截图 / 分层窗口提交回归。

## 通知文字修复

- 顶部通知的单行预览会把回车、换行、制表符和控制分隔符合并为空格，不再出现“群名□发消息人”。
- 详情与复制内容继续保留原始正文换行；冒号、可见符号、emoji 的连接符和变体选择符均保留。
- 通知列表与顶部通知使用一致的预览清理，并按清理后的标题匹配通知图标和时间。

## 升级与下载

- 适用于 Windows 10 2004（build 19041）及更新版本 / Windows 11，发行架构为 x64。
- 自包含单文件，无需另外安装 .NET。下载 `FluidBar.exe`，或解压 `FluidBar-5.0.0-win-x64.zip`。
- 沿用 4.x 的用户数据目录、设置和插件契约，升级不要求重置配置；可选插件仍按各自的最低宿主版本要求安装。
- 4.1 旧客户端若因更新缓存问题一直提示“已是最新版”，请先退出重启再检查；仍无法检测时，从本发行页手动下载并覆盖升级一次，保留用户数据目录即可。
- 更新检查继续使用 GitHub Releases 的版本与资产校验信息。
