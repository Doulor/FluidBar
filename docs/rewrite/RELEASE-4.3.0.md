# FluidBar 4.3.0（2026-11-09）

本次更新优化通知、剪贴板和文件暂存的阅读与操作，分开页面内滚动和切页，并修复更新检查误报“已是最新版”的问题。

## 卡片与通知

- 文件暂存改为两列卡片，分层显示文件名、类型、大小与目录，图片在后台加载真实缩略图。右上角提供常驻“移除”按钮，仅移除引用，保留原文件。
- 剪贴板支持多行摘要、等比图片预览及文件筛选下的两列卡片；保留搜索、预览、复制、固定和删除。
- 通知分开显示来源、标题、正文和时间，支持未读/验证码筛选、逐条详情、完整长标题与正文、大号验证码、复制及打开来源。
- 通知清除可以撤销，恢复历史不重放通知；已读与撤销状态立即刷新，返回详情前的列表位置。

## 滚轮与大小

- 页面内容中的普通纵向滚轮只滚动内容，空列表和滚动边界也不跳到别的页面。通过侧栏、横向滚轮或 Shift＋滚轮切换页面。
- 修复原生窗口解析向下滚轮参数时发生整数溢出、丢弃滚动事件的问题。
- 外观设置新增岛体大小调节，与文字大小分别控制；绘制、点击区域和拖动按相同缩放计算。

## 软件内更新

- 修复 HTTP 304 缓存命中被误报为“已是最新版”、从而清掉已有更新提示的问题。
- 缓存命中后仍按所选稳定版/预览版通道及当前安装版本判断更新；没有对应缓存时请求完整列表。
- 保持已下载并验证完成的安装包状态，不因重复检查而丢失安装入口。

### 4.1 用户升级提示

4.1 的客户端已经包含缓存判断错误，修复新版并不能直接修改旧客户端。若反复检查显示“已是最新版”，请退出后重新启动，避免连续点击检查；如果仍无法发现新版，可从正式发行页下载 4.3.0，退出旧实例后覆盖原程序。保留用户数据目录即可继续使用已有设置和插件。

发行文件：`FluidBar.exe`、`FluidBar-4.3.0-win-x64.zip` 与 `publish-4.3.0.json`。下载与安装仍执行 SHA-256 校验；当前发行未配置 Authenticode 签名。
