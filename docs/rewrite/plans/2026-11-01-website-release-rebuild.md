# FluidBar 4.0 正式版官网重构

日期：2026-11-01（Asia/Shanghai）

用户授权：抛开旧版，完整重构官网并自由设计；沿用此前的测试、部署、线上验证和聚焦提交要求。

## 设计方向

面向 Windows 用户的正式版产品发布页。采用冷银白、日光蓝壁纸、深色真实产品界面；原生 CSS 与现有 React/Phosphor 实现。DESIGN_VARIANCE 7、MOTION_INTENSITY 4、VISUAL_DENSITY 3。动效仅用于内容进入和交互反馈，支持减少动态效果。

整体顺序：产品体验 → 自定义外观 → 可选插件 → 常驻与开源 → 正式版下载。保留旧导航锚点。首屏为集中标题与完整桌面演示；外观为实物预览与配置；插件为两个真实市场条目与开发文档；品质区为可核查数字和现有艺术卡；下载使用明亮发布面板、真实统计、安装与 FAQ。

真实同源 prototype2 iframe、六页 pager、postMessage、媒体时钟、440×284 展开与 226×40 媒体尺寸保持。只扩展网页嵌入视口，不改产品逻辑。材质控件在 IslandLab 内，选择时展开预览。保留真实下载与近 24 小时活跃安装口径。

## 实施

1. 核对 4.0.0 发布文件、当前原型、线上桌面/手机页面以及签名市场基线。
2. 生成并优化一张原创日光桌面壁纸；重写设计 token、基础布局、导航、五个内容区域和页脚，移除旧页面不再使用的章节样式与材质研究组件。
3. 扩展 PrototypeFrame 的宽屏演示模式，保留默认嵌入行为和 ready 后发送队列；替换官网嵌入壁纸。
4. 更新正式版元信息、分享图以及有关旧版结构/预览版下载的测试断言；继续验证真实功能和签名静态层。
5. 运行 pnpm check，1440×1000 / 390×844 及边界宽度检查；部署 Pages 后再运行线上交互和静态市场验证。
6. 更新 CHANGELOG/STATUS/README，提交本次官网文件。清理本轮 dist/test-results，保留检查日志与截图。

## 市场基线

本轮开始时 marketplace/index.json 与 website/public/market/index.json 已不一致。官网现有索引包含正式发布的倒计时、文件暂存及两个示例插件；当前 prebuild 已从线上签名目录同步。本轮保留现有线上签名源与字节，不重签、不用旧根目录索引回滚已发布条目。部署前后对照官网当前签名索引哈希。
