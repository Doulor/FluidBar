# 插件市场发布链路修复

2026-10-31。用户反馈倒计时、文件暂存未出现在市场；本地打包不等于市场发布。

实测：线上只含两个示例；发布环境扫描 `plugins/samples`。最近成功发布产物为 fd96eb7，线上却为 77d1eb0；两个下载包均与线上索引的 SHA-256 不同。

- [ ] 发布发现统一扫描插件源目录，排除 bin/obj，显式检查仓库必需插件清单，避免遗漏。
- [ ] 已发布的同版本安装包禁止覆盖；重跑只复用相同字节，变更必须升版本。
- [ ] 网站构建使用当前线上或 CI 显式提供的签名索引，按目录生成全部插件的页面/资源，保留原始签名字节；不再用提交中的旧索引覆盖线上。
- [ ] 部署后检查索引原始字节、版本分片、安装包 SHA-256/大小及签名，出现错误即失败。
- [ ] 客户端每次市场刷新重新条件请求索引，消除进程内永久缓存；错误日志准确描述生产信任配置。
- [ ] 回归测试、四插件离线签名发布/安装演练、线上只读复查，更新契约和发布说明。
- [ ] 公开发布：代码、工作流、插件及环境配置需一起进入 main，再由受保护环境签名部署；本地演练不改生产密钥、不默认安装插件。
