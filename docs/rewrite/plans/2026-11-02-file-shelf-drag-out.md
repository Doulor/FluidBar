# 文件暂存向外拖动复制

2026-11-02。用户明确要求像拖入一样，从卡片直接拖出复制。

采用宿主声明式文件拖动数据和 Windows OLE Copy 拖放：文件行轻点在释放时执行原复制命令，移动超过 6 DIP 后交给原生拖动，取消/成功均保留暂存和原文件。文件行不会触发翻页或窗口移动。原生拖放期间暂停全局鼠标钩子的拦截，完成后恢复；卡片不会在拖动期间自动收起。
