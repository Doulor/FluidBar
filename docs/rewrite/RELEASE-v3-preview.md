## 本版新增

### 1. 液态玻璃材质（第三个材质，与黑曜石 / 模拟玻璃同级）

- 真实桌面抓屏 → 1/6 降采样 + 高斯模糊 + 饱和度 → 画进壳体路径 → 30% 染色 → 雾面 → 边缘高光。
- **所有岛面共用一条绘制路径**（`TryPaintBackdropSurface`）：主岛壳体、分裂小岛、堆叠残影、**预览带小岛**都能是玻璃。
- 抓屏自遮蔽（mask）：壳体 ±18 DIP、每个分裂胶囊、预览带（壳体下方 56 DIP）都会被从抓屏里抹掉，避免自查自。
- 跟随桌面明暗：亮度只在**岛足迹**内统计，亮底→瓷白玻璃+深色字，暗底→黑曜石+白字；亮度 80 ms 缓动 + 110 ms 交叉淡入（响应约 0.3 s）。

### 2. 柔化让位（右键手动）

- 右键主岛 = 柔化（模糊 + 降饱和），再右键 = 恢复；3 秒无交互自动恢复。
- 场景级 `SaveLayer`，三种材质同等生效。
- 让位期间点击穿透（`WS_EX_TRANSPARENT`），进程默认 BelowNormal 优先级。

### 3. 多 agent 堆叠环形图标

- 1 个会话：单环 + 180° 弧（0.9 s/圈）。
- 2 个：内层叠一个**逆时针 1.35 s** 的环。
- 3 个：中间变成**发光实心圆点**（不再加环）。
- 出现 = 从外环"分裂"，结束 = "融回"外环；超过 3 个不显示。
- **颜色按工具**：同一个工具（例如都是 DeepSeek Harness）三环同色（`#4D6BFE`），不同工具才异色。
- 紧凑胶囊 / 分裂小岛 / 展开页 agent 行**共用同一个 `AgentRingStack.Draw`**，样式完全一致。
- 环数 = 当前**打开着的**会话数（Running/Waiting），实时增减。

### 4. 稳定性与观感修复

- 修掉"岛一闪一闪变透明"：背景交叉淡入曾把壳体不透明度稀释到 ~88%（合成 alpha = 1-(1-t)²），现改为"旧图满不透明打底 + 新图按 t 叠加"。
- 修掉启动瞬间露出旧的不透明样式：首帧等抓屏就位（上限 900 ms）。
- 分层窗口改双缓冲 DIB + 整帧提交，避免合成器读到半张表面。
- 边缘亮度加滞回（≥0.15 才重算），外圈不再随抓屏节奏呼吸；折射带默认关闭（曾以 8 Hz 频闪）。
- 白底可读性：玻璃自适应调色板 + 浅色文字加投影。
