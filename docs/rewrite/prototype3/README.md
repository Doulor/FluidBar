# 展开卡片重构原型 A —— Telegram 语言

> 打开方式：双击 `docs/rewrite/prototype3/index.html`（单文件，无外部依赖，无需构建）。
> 这是**交互原型**，不是最终皮肤；配色与玻璃参数仍以设置面板那套 tokens 为准。

## 为什么重做

现在的展开卡片问题不是「好不好看」，是**一次点击之后没有下一步**：

1. **空间浪费**：488 × 384 里塞了一列居中卡片 + 大留白，正文区实际只有 ~300 px 宽、5 行可见；
   详情要看内容只能重新展开一次。
2. **流程断点**：剪贴板要「展开 → 找 → 点 → 粘贴」四步；通知要「展开 → 找 → 点 → 自己关掉」；
   没有搜索、没有多选、没有批处理、没有键盘路径。
3. **命中区域**：行高偏小、行内没有操作位，鼠标要精确移动到文字上。

## 借鉴 Telegram 的四件事（只借机制，不借皮肤）

| Telegram 的机制 | 这里的落法 | 解决什么 |
| --- | --- | --- |
| 三栏：文件夹 / 会话列表 / 消息 | 页轨 52 px / 列表 / 详情 268 px | 选中即预览，不需要二次展开 |
| 会话行：头像 + 标题 + 摘要 + 时间 + hover 操作 | 行 = 类型图标 + 标题 + 摘要 + 时间 + hover 三键 | 行高 56 px，整行可点，操作不抢焦点 |
| 侧滑删除、长按多选、右键菜单 | 通知行左右拖拽划走（阈值 120 px，回弹）；Ctrl/Shift 多选；右键菜单 | 批处理不需要进设置页 |
| 分段的 spring 动效（面板、行、菜单、浮层） | 120 / 180 / 260 ms 三档 + 两条缓动曲线 | 大位移用弹簧，颜色/透明度用缓出 |

动效参数（`--dur-1/2/3` + `--ease`/`--spring`）：
`--ease: cubic-bezier(.16,1,.3,1)`（位移/淡入）、`--spring: cubic-bezier(.2,1.18,.34,1)`（面板、菜单、下钻）。
行入场按 12 ms 交错，最多 8 行（≈96 ms），超过就不再延迟，避免长列表末尾发飘。

## 两种尺寸，同一个骨架（这是要你拍板的点）

| | 488 × 437（现状尺寸档） | 720 × 459（建议尺寸档） |
| --- | --- | --- |
| 列 | 页轨 + 列表（详情改为**下钻滑入**） | 页轨 + 列表 + 详情常驻 |
| 段控 | 隐藏（页轨已承担导航） | 显示 |
| 可见行 | 5–6 | 6–7（列表 398 px 宽） |
| 复制路径 | 点行 → 下钻 → 复制 | 点行即选中，回车复制（不换页） |

原型里右上角那个斜箭头按钮、以及左侧说明条的按钮都能切换两档，直接对比手感。
**我的建议**：日常用 720 档；488 档只在屏幕空间紧张（小屏/多屏）时作为降级。

## 布局与尺寸（实测）

- 面板 720 × 459，正文区 352 px；三列 `52 / 398 / 268`；行 56 px（舒适） / 50 px（紧凑）。
- 行内命中：标题区整行可点，右侧三键 22 × 22，hover 才出现，不遮挡文字。
- 全部状态无横向溢出（唯一「溢出」是标题省略号与下钻面板的 `translateX(102%)`，都被容器裁掉）。

## 键盘路径（和鼠标同权，这是「顺手」的关键）

`1`/`2`/`3` 切页 · `↑``↓``Home``End` 选 · `Enter` 执行（复制 / 打开）· `Space` 预览 ·
`Ctrl`+点击 多选 · `Shift`+点击 连选 · `Ctrl+A` 全选 · `Del` 删除 · `P` 固定 ·
`Ctrl+K` 搜索 · `Esc` 返回（下钻 → 清搜索 → 收起）· `?` 帮助。

## 剪贴板流程（3 步 → 1 步）

1. 打开卡片默认落在**剪贴板**页（最近一次用的页），第一行默认选中。
2. 输入即搜（标题/摘要/正文都参与，命中高亮），筛选 chip：全部 / 已固定 / 图片 / 链接。
3. `Enter` 复制 → 行闪一下 + 顶部 toast，**卡片不收**（可以连着复制第二条）。

固定项永远置顶且不受筛选影响顺序；右键有「复制 / 固定 / 删除」。

## 通知流程（批处理是一等公民）

- 按「未读 / 更早」分组，未读计数同步到页轨角标。
- 单条：`Enter` 打开并自动标已读（不再需要「点完再手动关」）。
- 划走：左右拖 > 120 px 删除，< 120 px 弹回原位（弹簧），删除有 180 ms 退出动效。
- 批量：`Ctrl+A` 或 `Shift` 连选后 `Del`；「全部清除」只清已读，避免误伤未读。

## 要移植到岛里需要补的能力

1. **列表虚拟化/固定行高**：Skia 侧按行高常量排版，别按文本测量撑开（现在通知行是测量出来的）。
2. **输入焦点**：岛是 `WS_EX_NOACTIVATE` 的 layered window，搜索框需要「软焦点」方案——
   建议按键直接进搜索缓冲（本地字符拼装），不依赖真实焦点；IME 走合成窗口。
3. **拖拽**：只需在岛内跟踪 pointer 与阈值，滑走的行用 `translateX` + 透明度，命中判定按行矩形。
4. **动效**：现有帧钟已能跑 60 fps，弹簧用固定时长的曲线近似即可（不必真物理积分）。
5. **下钻面板**：488 档要么做滑入详情，要么把详情做成「行内二次展开」，两者都不需要额外窗口。


## 修订 A2（2026-10-26，用户反馈「完全糊在一起，啥都看不见」）

第一版是**我的错**，三处硬伤，全部用像素与对比度数据定位：

| 问题 | 原因 | 改法 |
| --- | --- | --- |
| 整张卡像一层雾 | 面板是 `rgba(15,18,24,0.8)` 再叠 `backdrop-filter: blur(26px)`，20% 的背景被 26px 模糊透上来 | 面板改**实心** `#12151c`，玻璃只作为可选档（右上「玻璃：开/关」，默认关） |
| 行内元素互相挤压 | `.row__meta` 是 `flex-direction: column`，时间在上、操作键被挤到第二行（70×40 挤在 56px 行里） | 行改成固定三列 `28px / 1fr / 78px`，时间与操作键同一行，操作键**预留 70px 宽度**，hover 只改透明度→**零回流**（实测 392×52 → 392×52） |
| 小字看不见 | 次要文字 `#6c7686` @11.5px，对比度 **3.79:1** | 提到 `#9aa6b7` @12px，对比度 **7.40:1**；标题 16.9:1；全部 ≥AA |

顺带：正文字号整体抬一档（标题 13.5 / 次要 12 / 时间 11 / 按钮 12.5），行高 56，面板 720×460，
正文列 `56 / 390 / 272`；新增**缩放控制**（100 / 115 / 130%）——不同 DPI 缩放下自己挑一个舒服的。

### 量化对比（1440×900 截图解码后按卡片区域统计 8×8 块）

| 指标 | 旧（糊） | 新（实心） |
| --- | --- | --- |
| 平坦「雾」块占比 | 15.2% | **4.5%** |
| 有明确边缘的块占比 | 56.7% | **74.1%** |
| 卡片局部对比度 std | 53.3 | **63.3** |
| 次要文字对比度 | 3.79:1 | **7.40:1** |

几何校验：面板 720×460、7 行、行高 56px、页面无滚动、`panel` 内**零**未被裁剪的溢出元素、
缩放 130% 时 936×596 仍在视口内、控制台 0 error / 0 warning。
