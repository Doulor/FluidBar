# FluidBar 4.2.0（2026-11-07）

本次更新新增灵动岛拖动定位，完善设置保存，并改善文件暂存拖出预览的跟手体验。

## 拖动与操作提示

- 普通拖动可临时移动灵动岛；松手停留约 1.2 秒后，以弹性动画返回原位置。
- 按住 Ctrl 拖动可保存新位置，重启后恢复；按住 Ctrl 单击可回到默认位置。
- 修正透明窗口尺寸限制拖动范围的问题，可移动到屏幕左右及底部可用区域，兼容不同 DPI。
- 设置的“通用 → 鼠标操作”集中展示拖动、Ctrl 操作及右键临时隐去的使用方法。

## 设置与状态反馈

- 移除不起作用的强调色选择和封面取色选项。
- 修复多项设置保存后重启丢失，以及重置、导入后设置界面未同步刷新的问题。
- Agent 运行状态插件首次启动默认开启；已有的插件启用选择继续保留。
- 移除遮挡内容的“操作已完成”提示；处理中、失败及不可用反馈继续显示。
- 媒体插件支持调节已读歌词发光强度，并保存配置。
- 修复倒计时快速反复暂停 / 继续时偶发耗尽调度额度，以及完成后的调度重复清理异常。
- 补齐无蓝牙设备或不支持的 Windows 会话下的空数据状态。

## 文件暂存

- 拖出预览使用独立原生消息线程跟随鼠标，复用预先绘制的图片，减少目标应用拖放回调阻塞引起的卡顿。
- 松手或按 Esc 立即移除拖出预览，不必等待目标应用完成复制。
- 修复拖出期间插件注册变化可能导致源窗口误报复制成功的问题，调整高 DPI 下的预览间距。
- 保持只复制语义，原文件及暂存引用保留；已安装的文件暂存插件可继续使用。

## 发行方式

- 版本统一为 **4.2.0**，以 `v4.2.0` 标签对应的源码构建；发行流程执行完整解决方案回归。
- 本地 Release 完整回归 **3004 项通过**，覆盖核心、SDK、Windows 平台、架构、插件宿主、界面、内置插件、集成、渲染和可选插件。
- `FluidBar.exe`：Windows x64、Release、自包含单文件，无需额外安装 .NET。
- `FluidBar-4.2.0-win-x64.zip`：发行压缩包。
- `publish-4.2.0.json`：版本、构建提交、文件大小及 SHA-256 校验清单。

从托盘退出旧版后运行新版即可，已有设置与已安装插件会保留。延续既有未签名发行方式，应用内更新校验 GitHub Release 资产 SHA-256。
