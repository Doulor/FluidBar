# FluidBar 5.1.0（2026-11-11）

本次修复“更新已下载，点击重启并安装后程序退出，既未更新也未重启”的安装流程。保留 5.0 的统一蓝色液面图标、详情页滚动、液态玻璃与通知文字修复。

## 更新安装修复

- 支持实际宿主路径更新。浏览器生成的 `FluidBar (1).exe`、中文目录、带空格 / 单引号的路径及用户自行改名的程序均可使用。
- 助手先把新版暂存到目标同目录、核对 SHA-256，并确认就绪，主程序才退出；助手启动、脚本执行或准备失败时，当前程序保持运行。
- 不再把便携包当作安装器直接并行运行，避免新版撞上旧实例的单实例互斥锁后退出，接着旧版也关闭。
- 等待旧进程结束后再替换，遇到文件占用最多重试 60 秒；以原子替换保留旧 EXE，并核对替换后文件。
- 使用程序所在目录作为重启工作目录；替换失败保留旧文件，无法创建新版进程时尝试恢复并重新打开旧版。
- 助手记录准备、等待、重试、重启 PID 和恢复结果。正常客户端日志位于 `%APPDATA%\FluidBar\updates\install.log`；恢复失败时日志保留备份文件路径。

## 旧版用户如何升级

**4.3.0 / 原 5.0.0 的更新器不包含本修复。** 下载新版不会改变正在执行的旧更新器代码。如果此前点击“重启并安装”后程序消失，请手动覆盖到 5.1.0 一次：

1. 从系统托盘退出旧版，确认旧实例已结束。
2. 下载本页 `FluidBar.exe`，或解压 `FluidBar-5.1.0-win-x64.zip`，替换原软件目录中的旧程序后启动。
3. 如果旧文件名为 `FluidBar (1).exe`，可以保留该名称覆盖，避免原快捷方式仍指向旧文件。
4. 设置与插件数据继续使用原用户数据目录，不需要重置。不要直接在 `%APPDATA%\FluidBar\updates` 更新缓存目录内长期运行程序。

4.1 用户如仍遇到检测不到更新的问题，同样可直接手动覆盖升级。5.1.0 继续保留已有更新缓存修复。

## 验证与下载

- 更新助手回归覆盖真实 Windows PowerShell 5.1 执行、短暂文件锁、中文 / 单引号 / 改名路径、助手准备失败、新程序实际启动，以及启动失败后的旧版恢复与重启。
- 正式发行通过第一方编译警告门禁及完整解决方案测试。
- Windows 10 2004（build 19041）及更新版本 / Windows 11，x64 自包含单文件，无需另装 .NET。
- 发行文件：`FluidBar.exe`、`FluidBar-5.1.0-win-x64.zip`、`publish-5.1.0.json`。校验清单包含 EXE / ZIP 的 SHA-256、构建版本与源码提交。
- 当前发行未配置 Windows Authenticode 签名；应用内更新继续要求 GitHub 资产 SHA-256 校验。

原 4.3.0 / 5.0.0 标签与发行资产保持不变，5.1.0 通过独立标签发布。
