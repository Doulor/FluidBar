# 子灵动岛（卫星球）视觉与动效规范 v1

> 结论性规范：任何实现都必须满足本文件，测试与像素闸门以此为准。

## 1. 形态

| 项 | 规则 |
| --- | --- |
| 外形 | **纯圆**，禁止胶囊、禁止方形 |
| 直径 | = 紧凑主岛高度（36–40 DIP） |
| 底色 | 与主岛同色（Obsidian `#08080A`），逐字节一致 |
| 描边 | 无外描边；仅内部 `LineStrong` 1 DIP（若实现需要边界） |
| 排列 | 与主岛同一基线，间距 8 DIP；优先右侧，放不下自动左侧 |
| 数量 | 最多 2 个；第 3 个起折叠为主岛 `+N` 芯片 |

## 2. 内容（每种活动只有一个元素）

| 活动 | 球内内容 | 禁止 |
| --- | --- | --- |
| Agent | **只有一条蓝色圆弧**（2 DIP、圆头端点、180° 扫角、120°/s 顺时针） | 图标、文字、状态点、暂停键 |
| 媒体 | **黑球内一个圆角方形封面**（内缩 4 DIP，边长=直径−8，圆角=边长 22.5%，**contain 完整显示不裁切**） | 圆形裁剪、cover 裁切、附加图标 |
| 其它 | 单个中性图标（无封面时媒体也用白色音符） | 任何附加元素 |

## 3. 材质（iOS L0–L4 映射）

| 层 | 在球上的表现 |
| --- | --- |
| L0 | 球体填充 `#08080A`，无渐变 |
| L3 | 顶部 1 DIP 白色高光，alpha **8.6%**（区间 6–10%），向下 55% 高度淡出 |
| L0 阴影 | 球底黑 22.7%（区间 15–25%）自 50% 高度起，形成体积 |
| 封面内框 | 1 DIP 内描边白 7%（区间 5–10%）+ 顶部内阴影黑 18%，top inset 沿 45% 深度 |
| 强调色 | **容器禁止任何 accent**；只有内容（封面、Agent 蓝环、语义红徽标）可有颜色 |

## 4. 动效

| 阶段 | 参数 |
| --- | --- |
| 出生 | 总时长 0.445s；预压 0.92 保持 60ms；沿运动方向拉伸 8%（τ=0.16s）；落位过冲 4.6% |
| 融合 | 反向；越过落点 2% 后 80ms 归零 |
| hover | 1.02 + 高光增强 0.35 |
| press | 0.94 + 亮度 −6% + 内阴影 0.18（与主岛一致） |
| 呼吸 | 空闲时整体 ±1.2%，4s 周期 |
| 可打断 | 任意时刻切换只改 target，不重置 value/velocity；位姿连续（1e-6） |

## 5. 验收闸门

- `tests/FluidBar.Island.Tests/SatelliteVisualQualityTests.cs`：材质区间（rim 6–10%、hairline 5–10%、球底阴影 15–25%、press 0.18、环速 110–130°/s、样式层无 accent）
- `tests/FluidBar.Island.Tests/SplitSatellitePolishTests.cs`：像素级（rim 亮度差 0.05–0.11、hairline 7.2、frames 路径必须消费 `RingAngleDegrees`）
- 像素统计：球内除内容像素外无非中性色；球底色与主岛逐字节一致

## 6. 历史教训（不要再犯）

1. 曾经做过「胶囊 + 强调色环 + 灰状态点 + 暂停键」——用户明确否决：**噪音**。
2. 曾经把封面**圆形裁剪**——用户要的是**完整封面装进圆角方框**。
3. 曾经两条线各写一个环速（260 vs 120）——参数必须以本规范为唯一来源。
