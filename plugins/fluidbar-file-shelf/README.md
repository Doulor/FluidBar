# 文件暂存插件

更新：2026-11-02，1.0.3。独立可选插件，默认不安装、不启用。

1.0.3 要求 FluidBar 4.1.0 或更新版本，以使用新增的复制和文件拖出契约；先升级宿主再更新插件。宿主用实际发行版本执行安装/加载兼容性检查。

安装并启用后，将资源管理器中的文件或文件夹拖到灵动岛，岛会展开并切换到文件暂存卡片。非空时，收起的胶囊显示文件图标、数量和首个文件名；点击胶囊返回暂存卡片。其他临时系统提示可以暂时覆盖它，提示结束后恢复。

在卡片内按住文件名向外拖动，将文件直接拖到资源管理器目标文件夹或接收文件的应用，松手完成复制。拖动超过 6 DIP 后启动 Windows 原生拖放，光标显示复制反馈；按 Esc 取消。拖出成功或取消都保留暂存引用，原文件始终保留，不会变成移动操作。

轻点文件名仍可复制到系统剪贴板，然后在目标文件夹按 `Ctrl+V` 粘贴。顶部「复制全部文件」一次复制全部暂存项；每行「移除」及顶部「清空」仅移除引用。剪贴板复制成功/失败在顶部状态行显示，缺失文件不会被悄悄移除。

新版宿主在卡片外持续显示带文件名、数量和复制提示的鼠标跟随预览；目标不支持拖放时保留禁止光标，松手和取消后清除预览。卡片文件名最多两行，父目录单独显示，右上角 × 移除引用；列表溢出时显示滚动提示。剪贴板卡片也采用两行摘要和独立操作栏，文件摘要优先显示文件名，复制内容仍使用原始路径。

最多保留 32 项引用，规范化路径后去重；每页 16 项，卡片内滚动查看，顶部切换上一页/下一页。引用自动保存，重启后恢复。从不移动、删除或重命名原文件；源文件改名、移动或删除后，需要重新拖入。新版声明剪贴板写入权限，仅响应显式复制操作，不读取剪贴板。

拖出需要本次更新的 FluidBar 宿主。宿主也兼容 1.0.0/1.0.1 已有文件行引用，这两个版本无需重装插件即可拖出；1.0.2 使用显式文件拖出元数据并更新操作提示。旧宿主不支持新增的拖出交互。

构建：`dotnet build plugins/fluidbar-file-shelf -c Release`。
打包：`dotnet run --project src/FluidBar.Cli -- pack --plugin plugins/fluidbar-file-shelf --configuration Release --out build/plugins/fluidbar-file-shelf-1.0.3.fbp`。
安装入口为设置中的「从文件安装」。新宿主提供文件暂存 UI 能力；不支持该能力的旧宿主会明确报告不可用。
